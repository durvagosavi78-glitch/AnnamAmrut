# 🌿 AnnamAmrut — Bridging Surplus & Sustenance

**AnnamAmrut** is a web-based food rescue prototype designed to help connect surplus food donors, NGOs, and volunteers to reduce food waste and support communities in need.

The platform demonstrates how technology can streamline food donation, rescue coordination, and social impact tracking through a unified digital experience.

## ✨ Features

- 🍱 **Food Donation Management** — Explore the food donation workflow and manage surplus food donations.
- 🏢 **Role-Based Dashboards** — Switch between demo personas for restaurants, individual donors, NGOs, and volunteers.
- 🗺️ **Food Rescue Map** — Explore the map-based rescue interface for food rescue coordination.
- 🤝 **NGO Rescue Hub** — View the NGO-focused interface for coordinating food rescue activities.
- 🏆 **Community Leaderboard** — Recognize community contributions and encourage participation.
- 🌱 **Impact Tracking** — Explore food rescue statistics, estimated environmental impact, and sustainability metrics.
- 💾 **Local Data Persistence** — Preserve selected application data in the browser using local storage.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) installed on your system
- npm (included with Node.js)
- Git (optional, for cloning the repository)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/durvagosavi78-glitch/AnnamAmrut.git
   ```

2. Navigate to the project directory:

   ```bash
   cd AnnamAmrut
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually `http://localhost:5173`.

### Build for Production

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🧪 Project Status

**Status:** Prototype / Demonstration Project

AnnamAmrut is a front-end prototype that demonstrates the proposed food rescue workflow using sample data and interactive UI components. It is intended to showcase the concept and user experience; a production deployment may require a backend, authentication, database integration, and verified real-time rescue data.

## 🌍 Vision

To encourage a more sustainable and compassionate food ecosystem by connecting surplus food with communities that need it, reducing avoidable food waste, and making collective impact easier to understand.
